# 校园点餐平台设计

## 目标

构建一个运行在阿里云 Linux 服务器上的 C 语言 TCP 点餐服务，以及一个运行在 6818 开发板上的 LVGL 点餐客户端。项目只覆盖菜单读取、购物车、总价计算和订单文件记录。

## 边界

- 不包含账户体系、真实支付、数据库、管理后台和库存扣减。
- 菜单从 `server/data/menu.txt` 读取；确认订单后追加写入 `server/data/orders.txt`。
- 服务端为每个 TCP 连接维护一份内存链表购物车；连接断开后释放该购物车。

## 目录职责

- `common/`：客户端和服务端共享的纯 C 协议定义。
- `server/`：可独立编译的菜单读取、链表购物车和 TCP 服务端。
- `client/`：LVGL 端的应用状态、网络适配和 UI 模块；图片放在 `client/assets/images/`。
- `docs/`：协议、运行和开发说明。

## 通信协议

使用 UTF-8 文本行，每条请求或响应以 `\n` 结束。字段使用 `|` 分隔。

| 方向 | 格式 | 说明 |
| --- | --- | --- |
| 客户端 -> 服务端 | `MENU` | 获取菜品列表 |
| 客户端 -> 服务端 | `ADD|<dish_id>|<quantity>` | 添加或增加菜品数量 |
| 客户端 -> 服务端 | `REMOVE|<dish_id>` | 从购物车移除菜品 |
| 客户端 -> 服务端 | `CART` | 获取购物车与总价 |
| 客户端 -> 服务端 | `SUBMIT` | 生成订单并清空购物车 |
| 服务端 -> 客户端 | `OK|...` | 成功响应 |
| 服务端 -> 客户端 | `ERROR|...` | 失败响应 |

## LVGL 页面

点餐主界面采用 800x480 固定三栏：左侧 150px 分类区，中间 430px 菜品卡片区，右侧 220px 购物车区。确认订单和网络异常使用模态弹窗；菜品图片资源由 `dish_id` 映射到 `client/assets/images/` 中的文件。

## 验收

1. 服务端能读取菜单文件、维护链表购物车并写入订单文件。
2. 服务端核心单元测试可通过 `make test` 执行。
3. 客户端目录中已分离状态、网络和 UI，不在一个 LVGL 源文件中堆叠功能。
